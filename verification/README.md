# Formal verification

This subtree contains proof-grade source associated with the public evidence
in this repository. It is deliberately separate from `docs/results/`:
numerical artifacts are observations, while Lean files are executable formal
proofs.

The formal-verification source is licensed under the [MIT License](LICENSE).
The repository's root CC BY 4.0 license continues to cover documentation and
published numerical material.
