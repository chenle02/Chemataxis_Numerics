# Cite this companion

Please cite both the Paper III manuscript and the exact repository revision
used in your work. The repository includes a machine-readable
[`CITATION.cff`](https://github.com/chenle02/Chemataxis_Numerics/blob/master/CITATION.cff)
file, which GitHub exposes through its **Cite this repository** panel.

## Suggested data citation

> Chen, Le; Ruau, Ian; and Shen, Wenxian (2026). *Chemotaxis Models III:
> Bifurcation — Numerical Companion and Data Archive*, version 0.1.0. GitHub.
> https://github.com/chenle02/Chemataxis_Numerics

Add the Git commit hash or release tag you used. For example:

```text
Repository revision: <40-character Git commit>
Accessed: YYYY-MM-DD
```

## Reuse note

Before quoting a threshold or bifurcation coefficient, check the case status in
the [Paper III evidence manifest](data/paper-iii-manifest.json). Only
`validated_current` records are approved as current paper evidence.
`under_review` records may contain corrected analytical metadata, but their
archived trajectories are not approved for a Paper III numerical claim.
